# 磁珠定焦工具：自动对齐版

本版先自动修正当前选区相对 reference 的水平、垂直偏差，再计算二维相关值和径向相关值。列表显示“图片、二维相关值、径向相关值、dx、dy、图样判定”。中心坐标输入（支持小数）和结果删除功能保留原来的操作方式；删除后的记录不会再导出。

## 启动

更新后关闭旧程序窗口，再双击 `启动定焦工具.cmd`。当前电脑优先使用已安装的配套 Python。

其他电脑安装 Python 3.10 或更新版本后运行：

```powershell
python -m pip install -r requirements.txt
python focus_gui.py
```

## 输入中心坐标

1. 加载 reference，在该面板填写“中心 X”和“中心 Y”，例如 `320.25`、`240.5`。
2. 点击“应用坐标”或按 Enter，检查中心标记和选区。
3. 加载当前图片，在当前面板填写本组珠的中心坐标。
4. 点击“比较”。它会读取最新输入的坐标，不必先按“应用坐标”。

坐标使用当前加载图片的原始像素：左上角为 `(0,0)`，X 向右，Y 向下。显示缩放不改变坐标单位。小数坐标用于确定初始对应位置；自动对齐会进一步修正当前图的残余偏差。对齐不会修改输入框里的坐标。

鼠标点击仍可作为快捷选择，坐标会填入输入框，可再精确修改。新图片会清空旧坐标。无效数字、NaN 或选区越界会提示修正，不添加结果。

`.npz` 保存的是参考选区及其局部中心。再次载入时，显示的是该选区图，输入框使用选区图的局部坐标；保存的小数中心会恢复。

## 自动平移对齐与相关值

1. 围绕输入的中心分别截取两张图的单珠选区；参考中心作为径向采样的基准。
2. 在“允许 XY 偏移”范围内搜索当前图的残余平移，使二维归一化相关系数（NCC）最大。默认每个方向为 ±8 px，并对峰附近的偏移作亚像素估计。
3. 对齐后计算二维相关值；两张图始终使用相同大小的有效内部区域，不补零、不使用首尾循环的像素。
4. 根据对齐关系修正当前图的采样中心，在相同半径上各取 720 个角度的强度样本，以双线性插值处理小数位置，再做角向平均。两条径向轮廓计算 Pearson 相关系数。

第四步等价于先把当前选区平移对齐，再围绕参考中心提取径向轮廓；程序直接在原始当前图上取样，避免再生成一张平移图片带来的重复插值。不缩放衍射环半径，也不搜索径向曲线的半径偏移。

`dx`、`dy` 表示当前选区相对参考选区的**残余偏移**，单位为像素。`dx > 0` 表示偏右，`dy > 0` 表示偏下；实际对齐方向为 `(-dx, -dy)`。例如输入相同中心，但当前珠实际偏右 4 px、偏上 3 px，结果应约为 `dx=4`、`dy=-3`。两组不同参考珠在整幅图上的绝对位置差不计入这两个数；若两张图输入的中心都准确，残余偏移通常接近零。

参考中心仍需尽量准确。自动对齐是使当前图匹配参考图，不能自行验证参考中心就是几何中心；不同珠的图样差异也可能影响平移估计。最佳平移落在搜索边界时，界面会提示复核，并暂停阈值判定。可调整当前中心或增加允许范围后再比较。将允许偏移设为 0 时关闭平移搜索。

| 输出 | 含义 |
|---|---|
| `ncc` | 对齐后有效内部区域的二维归一化相关值，范围 -1 到 1 |
| `radial_correlation` | 对齐后的径向轮廓相关值，范围 -1 到 1，越接近 1 通常表示轮廓越相似 |
| `shift_dx_px` / `shift_dy_px` | 选区间的残余偏移，即列表中的 dx、dy，单位 px |
| `alignment_at_limit` | 最佳平移是否位于允许范围的边界 |
| `matches_threshold` | 是否达到自定径向阈值；未设阈值或触发饱和检查时为空 |
| `quality_ok` | 是否通过平移边界和可选饱和检查，不代表所有图像质量问题均已排除 |
| `reference_id` | 参考选区与中心的标识 |

CSV 同时导出二维相关值、对齐后径向相关值和 dx、dy。图样判定仍根据**径向阈值**计算；恢复二维相关值不会改变这个判定依据。

选区边长默认 129 px，需为至少 33 的奇数。默认允许偏移 8 px 时，二维比较使用 109×109 px 内部区域；径向采样半径为 0.5、1.5、…、52.5 px。边缘为所有候选平移预留余量，使分数使用同等范围的有效像素。增加偏移范围会减少可用的采样半径；需要保留较大的衍射环时，也应增加选区边长。选区应包含主要衍射环且没有其他珠。“排除内圈”只影响径向轮廓，不改变二维对齐。

相似度阈值可留空。应根据真实图像及可接受焦位范围设置，不使用通用阈值保证定焦合格。相机上限已知时，可在“饱和值”填写实际值，例如 12 位相机填 4095；超过 1% 像素达到上限会提示复核并暂停阈值判定。

## 删除结果

- 选中一行或多行，点击“删除选中”，或按 Delete 键。
- Ctrl / Shift 支持多选。
- “清空列表”移除全部比较记录。
- 删除同步更新导出数据，CSV 只包含剩余结果。
- 删除正在显示的轮廓后，会显示最后一条剩余结果；全部删除后清空轮廓。

删除仅影响程序里的结果，不删除输入图片或已经保存的 CSV。

## Python 调用

```python
from bead_focus import Config, FocusReference, load_image

reference = FocusReference.from_image(
    load_image("reference.tif"),
    center=(320.25, 240.5),
    config=Config(roi_size=129, max_shift_px=8),
)
reference.save("reference.npz")

result = reference.compare(load_image("group1.tif"), center=(410.3, 285.75))
print("二维相关值：", result["ncc"])
print("对齐后径向相关值：", result["radial_correlation"])
print("dx、dy (px)：", result["shift_dx_px"], result["shift_dy_px"])
```

可直接输入相机提供的二维 NumPy 数组。省略 center 时使用图片中心，仅适合已居中的单珠图。

```powershell
python bead_focus.py init reference.tif --center 320.25 240.5 --max-shift 8 --output reference.npz
python bead_focus.py compare reference.npz group1.tif --center 410.3 285.75 --csv results.csv
```

批量输入已居中的单珠图可省略中心。整幅视野的珠位置不同，应使用 API 分别给中心，或界面逐张比较。

灰度 16 位 TIFF/PNG 保留原数值，不先转成 8 位。也支持单帧 BMP、JPEG、RGB 图和二维 `.npy`。定量比较优先使用无损原图。多帧 TIFF 必须用 `--frame` 选择一帧，界面使用导出的单帧图。

## Z 扫描

扫描先逐帧自动对齐，再按径向相关值选峰。CSV 中可以为每张图填写不同中心：

```csv
stage_z_nm,image_path,center_x,center_y
-100,scan_minus100.tif,410.3,285.75
0,scan_zero.tif,410.3,285.75
100,scan_plus100.tif,410.3,285.75
```

```powershell
python bead_focus.py scan reference.npz scan.csv --output scan_result.json --plot scan_curve.svg
```

至少提供三个不同 Z 位置并尽量覆盖峰两侧；相同位置的多帧分数会平均。结果包含 `best_radial_correlation`、最匹配的采样位置和局部插值估计；`frames` 保留各帧的二维相关值及 dx、dy。相关峰在扫描端点或存在多个同高峰时会提示复核。某帧的平移达到搜索边界时，需先修正该帧再选焦。

扫描台坐标来自你的输入，不是从相关值推导的珠高。跨珠轮廓接近不能单独证明物理 Z 相同；正式轨迹测量仍需本组珠的高度校准。

## 旧版 reference

可载入最初版和径向版的 `.npz`，保留选区并按本版算法重新计算。径向版已保存的小数中心继续恢复；最初版未保存小数中心，载入时使用选区中心。旧阈值自动清空，因为平移和有效采样范围改变后，旧分数与阈值不宜直接沿用。请根据本版结果重新设置并保存。

本版新保存的 reference 会记录允许偏移、精确中心及阈值，再次载入不会清空阈值。

## 模拟样例与验证

`example/` 是模拟圆环，不是实验图像或真实光学标定：

- `reference.npz` 可直接载入。
- 原始 `reference.tif`、`current_same_pattern.tif`、`current_different_ring.tif` 的中心为 `(128,128)`。
- `current_offset_center.tif` 的中心为 `(130.4,126.35)`，可输入此坐标演示精确选择；也可输入 `(128,128)` 演示自动修正约 `dx=2.4`、`dy=-1.65` 的中心偏差。示例结果 CSV 中最后两行分别演示这两种输入方式。
- `scan.csv` 和 `scan/` 演示径向选峰；Z 数字为模拟标签。


本版通过 30 项检查，包括整数和亚像素自动对齐、二维相关值、对齐后径向相关值、平移边界、小数中心、旧参考载入、16 位读取、扫描选峰、数字坐标输入、删除多行后的 CSV 导出和清空列表。没有用用户真实显微镜图像验证定焦偏差或纳米精度。
